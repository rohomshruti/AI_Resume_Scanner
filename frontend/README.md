# AI Resume Scanner

Frontend for the AI Resume Scanner.

## Frontend stack

- React
- JavaScript
- Vite
- Lucide React

The frontend does not use TypeScript, TanStack Router, TanStack Query, Tailwind CSS, or Lovable's Vite configuration.

## Run

```bash
npm install
npm run dev
```

The development server runs on:

http://localhost:8080

The resume analysis API is expected at:

http://127.0.0.1:8000
